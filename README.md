# QA Metrics & Release Readiness Dashboard

QA Metrics & Release Readiness Dashboard - Build a professional, executive-level QA Metrics and Release Readiness Dashboard called "QualityPulse". The application should feature an analytical interface using modern charts (bar, line, donut, and area charts) to display software quality data. Include metrics such as: Test Execution Pass/Fail rates over the last 30 days, Defect Density by feature module, Open Bugs broken down by Severity (Critical, High, Medium, Low), and an overall "Release Readiness Score" percentage. Add a top-level filter bar allowing users to switch between different mock projects or release versions (e.g., v2.1.0, v2.2.0). Provide a sidebar with a clean data-entry form or a simulated JSON upload tab so a user can dynamically update the dashboard metrics to see the charts animate and refresh in real-time.
